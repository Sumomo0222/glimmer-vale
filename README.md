# 微光谷物语 · Glimmer Vale

原创像素风农场生活模拟网页游戏。你继承了爷爷荒废的农场——清理土地、开垦播种、浇水收获、湖边钓鱼、建造设施，与五作息各异的村民相识，让微光镇重新繁荣起来。

## 🎮 在线游玩

**https://sumomo0222.github.io/glimmer-vale/**

## ✨ 特性

- 🌱 真实作物生长：6 种季节作物 × 4 个生长阶段，需开垦、播种、浇水、除虫式照料
- 🌙 昼夜循环：6:00 至次日 2:00，黎明/黄昏/深夜光照与点灯氛围
- 🍂 四季变化：春夏秋冬各 28 天，草木变色，换季作物枯萎
- 🌧️ 天气系统：晴/多云/雨/暴雨/雪，雨雪自动浇灌
- 👥 村民日程：5 位村民按时间在小镇/森林/湖边间移动，可对话交流
- 📜 任务日志：10 个主线任务，完成可提升「小镇恢复度」，全满触发通关结算
- 🎒 物品背包：种子/农产品/鱼获/材料，快捷栏 + 手持系统
- 🗺️ 地图切换：农场 / 微光镇 / 月影森林 / 月影湖 + 家，小地图与村民位置一览
- 🎣 钓鱼小游戏：时机提竿 + 收线博弈，修桥解锁深水稀有鱼
- 🔨 设施建造：洒水器 / 稻草人 / 鸡舍 / 小桥
- 💾 开始 / 保存 / 每日结算 / 重新开始完整流程（localStorage 自动存档）
- 📱 适配桌面与手机：虚拟摇杆 + 触屏按键

## 🕹️ 操作

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 移动 | WASD / 方向键 | 左侧摇杆 |
| 互动/使用 | 空格 / E | 「互动」按钮 |
| 使用工具 | F | 「工具」按钮 |
| 背包 / 任务 / 地图 / 菜单 | I / J / M / Esc | 顶部按钮 |

## 🛠️ 技术

零依赖单文件实现：全部像素美术（角色四向行走、瓦片、作物、建筑）由程序化像素绘制生成；WebAudio 合成音效；构建脚本将源码内联为 `dist/index.html`（约 157KB）。

```bash
node tools/build.js   # 重新构建 dist/index.html
```

素材与代码均为原创。
